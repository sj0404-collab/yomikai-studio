# yomikai-studio

Стенд для читалки **Koma** (АПК `koma-reader`): эмулятор студии APKForge, в
котором видно, **что читалка делает на самом деле** — какой текст берёт, в каком
порядке читает, что уходит в голос и что показывает нативная панель.

Это форк [APKForge Studio](https://github.com/sj0404-collab/apkforge-studio)
(`main`), который мы дорабатываем только под свои задачи: он не заменяет
студию, а служит испытательным стендом для читалки.

## Что здесь своего

| файл | зачем |
|---|---|
| `src/lib/komaShim.ts` | мосты Android-оболочки для страницы: `KomaSpeech` (системный TTS с событиями `start/end`), `KomaUi` (нативная панель), `KomaApp` (версия/обновление), `KomaPlugins` (плагины). Плюс `__komaTtsLog`, `__komaSpoken`, `__komaPanel`, `__komaCmd`, `__komaReport`, журнал прокрутки |
| `src/components/Emulator.tsx` | режим `?koma=1`: шире и выше экран, панель чтения **под экраном** (как нативная полоса под WebView), кнопки ▶/⏸/⏭/⟲/⏹, журнал «прочитано по порядку», **сверка с эталоном на экране**, кнопка «отчёт» |
| `koma/plugins/forge-emulator.json` | плагин стенда в обычном формате читалки (включая эталон для сверки). Читается dev-сервером при старте — правка файла меняет поведение без пересборки |
| `koma/live.py` | живой прогон: поставить АПК → страница манги → модели → распознать → прочитать → напечатать текст, порядок, сверку с эталоном, скриншоты |
| `koma/stand-check.py` | быстрая проверка самого стенда (мосты, панель, сверка, отчёт) — без манги и моделей |
| `koma/probe.py` | сборка «пробного» АПК: копия настоящего + наша страница как `assets/webapp/index.html` |
| `koma/setup.sh` | поднять окружение после сброса песочницы: библиотеки Chromium, playwright, swap 2 ГБ, dev-сервер на 5174 |

## Запуск

```bash
bash koma/setup.sh                       # один раз после сброса окружения
python3 koma/stand-check.py              # стенд годен?  (~10 с)
python3 koma/live.py \
  --apk /home/user/koma-reader-v1.9.42.apk \
  --page /home/user/kw9/koma-web.html \
  --image /home/user/koma-lab/dense-a.jpg   # живой прогон на манге (~40 с)
```

Открыть глазами: <http://localhost:5174/?koma=1> → «Open APK…» → пробный АПК
(его собирает `koma/probe.py`) → страница манги и модели **внутри приложения**
(кнопки «страница» и «модели»).

## Почему пробный АПК, а не настоящий

Настоящий АПК кладёт страницу в `assets/koma-web.html`, а эмулятор показывает
приложение только при наличии `assets/webapp/index.html`. Поэтому прогон ставит
копию настоящего АПК с одной добавленной записью — страницей. Манифест, модели,
иконки и подписи остаются настоящими, то есть проверяется та оболочка, что уходит
на телефон.

## Чего стенд не умеет

* нет настоящего Tera TTS: голос — мок с теми же событиями, что у `KomaSpeech`;
* Kotlin-движок чтения (`ReadEngine`) и Lens в браузере не запускаются — это
  проверяется только на телефоне;
* звуковые эффекты и дообучение распознавателя — не здесь, а в репозитории
  читалки.
